# Requisitos Não Funcionais — Saborfy

| ID     | Requisito |
|--------|---|
| RNF001 | O sistema deve exigir autenticação para acesso às funcionalidades protegidas. |
| RNF002 | O sistema deve implementar controle de acesso baseado no cargo do funcionário. |
| RNF003 | O sistema deve garantir o isolamento dos dados entre diferentes restaurantes. |
| RNF004 | As senhas dos usuários devem ser armazenadas de forma segura, utilizando técnicas adequadas de proteção e hash. |
| RNF005 | O sistema deve depender de conexão com a internet para seu funcionamento. |
| RNF006 | O sistema deve apresentar disponibilidade adequada para utilização durante o horário de funcionamento dos restaurantes. |
| RNF007 | O sistema deve apresentar tempo de resposta adequado para as operações comuns realizadas pelos usuários. |
| RNF008 | As alterações realizadas pelos usuários devem ser refletidas nas telas correspondentes sem atrasos que prejudiquem a operação. |
| RNF009 | A interface deve ser simples e intuitiva, permitindo que os funcionários utilizem o sistema sem treinamento complexo. |
| RNF010 | A aplicação deve possuir interface responsiva e adaptar-se a computadores, tablets e smartphones. |
| RNF011 | A interface destinada à cozinha deve priorizar a visualização rápida dos pedidos e seus respectivos status. |
| RNF012 | Pedidos prontos devem possuir destaque visual suficiente para serem facilmente identificados. |
| RNF013 | O sistema deve possuir uma arquitetura modular que facilite sua manutenção. |
| RNF014 | A arquitetura deve permitir a evolução do sistema e a inclusão de novas funcionalidades sem alterações excessivas nas funcionalidades existentes. |
| RNF015 | Os dados registrados pelo sistema devem possuir persistência em banco de dados. |
| RNF016 | O sistema deve ser disponibilizado como uma aplicação web. |
| RNF017 | A aplicação deve ser compatível com navegadores modernos utilizados em computadores, tablets e smartphones. |
| RNF018 | Os valores monetários devem utilizar o Real brasileiro (BRL) como moeda padrão. |
| RNF019 | As operações que utilizam data e horário devem considerar inicialmente o fuso horário do Brasil. |
